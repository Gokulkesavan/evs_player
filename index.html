Decoder settings

The .evs file does not store the audio bandwidth. Auto picks 48 kHz if 96/128 kbps frames are present, 32 kHz for 32/48/64 kbps, otherwise 16 kHz. Set it manually if you know the negotiated bw=. Changes apply on the next decode.
